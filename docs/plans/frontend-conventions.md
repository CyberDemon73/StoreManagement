# Frontend screen conventions (read before writing a screen)

Repo: Next.js 15 App Router, React 19, TypeScript strict (`noUncheckedIndexedAccess` on), Tailwind v4, lucide-react, recharts. Path alias `@/` → `src/`.

## Where things live
- Screen component: `src/screens/<area>/<Name>Screen.tsx` (`'use client'`, named export). First lines: a comment with route, roles and the API endpoints it calls.
- Route file: `src/app/(app)/<route>/page.tsx` — tiny: `export const metadata`, default export renders the screen. Pages that read `useSearchParams` must be wrapped in `<Suspense>` in the page file. Dynamic routes: `src/app/(app)/products/[id]/page.tsx` with `export default async function Page({ params }: { params: Promise<{ id: string }> }) { const { id } = await params; return <ProductDetailScreen id={id} />; }`.
- Auth pages live under `src/app/(auth)/<route>/page.tsx` (layout already centers a 420px card). `/login` exists.
- The `(app)` layout already handles: session redirect, AppShell (sidebar / rail / bottom tabs / top bar / search / notifications / View-as-seller banner / offline banner), and route→permission 403 from `src/lib/nav.ts`. Do NOT add nav or guards inside screens.

## Data
- Only through `import { api, ApiError } from '@/lib/api'`. Read `src/lib/api.ts` for the full surface; never import `@/mock/*` from a screen.
- Hooks in `src/lib/use-api.ts`: `useApi(fn, deps, {enabled})` → `{ data, error, loading, initial, refetch, setData }`; `useMutation(fn)` → `{ mutate, pending, error }`; `useBreakpoint()` → 'mobile'|'tablet'|'desktop'; `useOnline()`, `useDebounced(v, ms)`, `useLocalStorage(key, init)`.
- `useAuth()` from `@/lib/auth-context`: `{ user, role, can(permission), isManager, viewAsSeller }`. Hide cost/margin/profit UI with `auth.can('analytics.read')` or `auth.isManager`; design tables so the hidden column does not break alignment (use `when:` on DataTable columns).
- `useDateRange('30d')` from `@/lib/use-date-range` for report screens + `<DateRangePicker value onChange compact />`.
- Types from `@/types`. Money is integer minor units: format with `formatMoney(minor)` (`'EGP', { withCurrency, compact, signed }`), never divide yourself except through `MoneyInput`. Other helpers in `@/lib/format`: `formatNumber, formatPct, formatDate, formatTime, formatDateTime, formatRelativeDays, stockStatus(qty, threshold), PAYMENT_LABEL, SALE_STATUS_LABEL, MOVEMENT_LABEL, REASON_LABEL, initials`.
- Toasts: `const { toast } = useToast()` from `@/components/ui/Toast`; `toast({ kind: 'success'|'error'|'info'|'pending', title, body?, action? })`.

## Design rules
- Tokens only: `bg-bg bg-surface bg-surface-2 text-ink text-ink-2 text-ink-3 border-line bg-accent text-accent bg-accent-soft text-accent-ink`, status `ok/warn/danger/info` with `-soft` and `-ink` variants (`bg-warn-soft text-warn-ink`). Radii `rounded-card` (12) `rounded-input` (8). Shadow `shadow-float` only for floating things. Never hard-code hex except product tint/colour swatches from data.
- Text: `.eyebrow` utility for small caps labels; `.tabular` for numbers; `text-ink-3` is for icons/placeholders only (not text).
- Breakpoints: mobile <768 (`md:` starts tablet), desktop `xl:` ≥1280. Mobile gets cards and full-screen sheets; tablet two columns; desktop tables + drawers. Touch targets ≥ 44px on mobile (`size-11`, `min-h-11`, `Chip size="touch"`).
- Every data screen shows loading (skeleton mirroring layout), empty (icon + title + one sentence naming active filters + one action), error (`ErrorState` with retry) and keeps working offline for reads (the shell shows the banner).
- Accessibility: real `<button>`/`<a>`/`<input>` + `<label>`; `aria-label` on icon-only buttons; `aria-live="polite"` on cart totals; colour never the only signal (badge text, icons). Focus ring comes from globals.
- Named exports only (except Next pages). No default exports in screens. No `any`. Keep each screen file under ~600 lines; split sub-components into sibling files in the same folder when bigger.
- Copy tone: calm, specific, no exclamation marks. Numbers in EGP.
